Приложение · Заметки и дневник

Личный блокнот, который остаётся личным.

Блокнот — простое приложение для заметок и дневника. Все записи хранятся локально, на вашем устройстве. Синхронизация с Google Drive — отдельная функция, которую вы включаете сами и в любой момент можете отключить.

Политика конфиденциальности Условия использования

Что внутри

Локальное хранение

Заметки, теги и даты не покидают ваш телефон, пока вы сами не включите резервное копирование.

Защита блокировки

PIN-код или графический ключ для быстрого доступа только с вашего устройства.

Резервная копия в Google Drive

По желанию. Приложение видит только тот файл, который само создало — остальной диск ему недоступен.

Поиск, теги, сортировка

Быстрый поиск по записям, цветные теги, сортировка по дате или названию.

Коротко: без рекламы, без аналитики, без сбора данных на сторонних серверах. Подробности — в политике конфиденциальности.
